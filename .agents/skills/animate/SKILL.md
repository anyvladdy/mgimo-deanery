# CSS-анимация

1. Назови причину и частоту. Отклик на нажатие, смена состояния и связь панели с кнопкой могут оправдать короткий переход. Переходы между страницами, клавиатурные команды, выбор дня и появление каждой карточки по очереди оставляй мгновенными.
2. Начни с нативных HTML и CSS. Переиспользуй переменные длительности и плавности из [site.css](../../../src/ui/site.css), если они есть. Для нажатия ориентируйся на 100–160 мс, для небольшого всплывающего элемента на 125–200 мс, для меню на 150–250 мс. Для появления панели подходит быстрый старт `cubic-bezier(0.23, 1, 0.32, 1)`. Плавное начало и завершение через `ease-in-out` подходят для перемещения уже видимого элемента.
3. Для обратимой смены состояния перечисли изменяемые свойства в `transition`. Сдвиг и масштаб делай через `transform`, появление через `opacity`. Масштаб панели привяжи к кнопке и начни почти с её полного размера. Размеры и положение соседних блоков не должны колебаться.
4. Движение при наведении включай в `@media (hover: hover) and (pointer: fine)`. В `@media (prefers-reduced-motion: reduce)` убери сдвиг и масштаб или покажи итог сразу. Сразу передавай видимое состояние, фокус и результат действия. Отправка формы и подтверждение серверного результата следуют контракту маршрута.
5. На 360 px проверь быстрое повторное действие и закрытие во время перехода. Повтори с настройкой уменьшенного движения и клавиатурой. Опиши цель, длительность и наблюдаемый результат по [review-animations](../review-animations/SKILL.md).

Источник и лицензия в [каталоге навыков](../../ECC-SKILLS.md).
