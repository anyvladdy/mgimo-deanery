# Личный ассистент

Войдите в цифровой деканат, откройте «Сервисы» → «Личный ассистент» и нажмите «Выпустить токен». Скопируйте его с экрана выдачи и сохраните в настройках секретов ассистента. Токен действует 30 суток с момента выпуска. Кнопки «Заменить токен» и «Отозвать токен» сразу прекращают действие прежнего токена.

1. Скачайте спецификацию OpenAPI со страницы «Личный ассистент» или по адресу `/api/v1/openapi.json`. Импортируйте её в ассистента и укажите базовый HTTPS-адрес своего деканата. Если импорт выполняется из локального файла и требует абсолютного адреса, укажите его в `servers[0].url` своей копии спецификации.
2. Настройте HTTP Bearer-аутентификацию. Ассистент передаёт токен только в заголовке `Authorization`. Адрес деканата должен быть доступен из среды, в которой работает ассистент. Для локального демо подойдёт клиент на том же компьютере.
3. В расписании ассистента создайте регулярный вызов `listDeadlines`, например ежедневно в 08:00 МСК с `days=7`. Используйте `id` и `date` для дедупликации напоминаний. При `401` обновите токен в настройках ассистента.

Пример запроса к локальному демо с условным токеном

```sh
curl --fail-with-body \
  --header 'Authorization: Bearer REPLACE_WITH_YOUR_TOKEN' \
  'http://127.0.0.1:3100/api/v1/deadlines?days=7'
```

Допустимый `days` — целое число от 1 до 90. По умолчанию запрашиваются 30 календарных дней, включая сегодня по московскому времени. Ответ содержит границы `from` и `to` и массив `deadlines`. В него входят открытые личные дедлайны, групповые сроки и сроки оплаты из активных модулей. `href`, если есть, открывает страницу личного кабинета. Для неё потребуется обычный вход в деканат. Поле `time` содержит время по Москве в формате ЧЧ:ММ, если срок задан со временем.

| Код | Причина |
|---|---|
| `200` | Запрос выполнен. `deadlines` может быть пустым. |
| `400` | Значение `days` недопустимо, параметр передан несколько раз или передан неизвестный параметр. |
| `401` | Токен отсутствует, просрочен, отозван или заменён. |
