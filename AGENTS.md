# Работа с цифровым деканатом

Держите функцию в каталоге её модуля. Обнаружение маршрутов, сервисов и пунктов меню проходит через Harness. Маршруты и контракты описаны в [архитектуре](docs/ARCHITECTURE.md) и [руководстве по модулям](docs/HARNESS.md).

Серверный HTML формируйте шаблонами `hono/html`. Личные данные выбирайте по проверенной сессии. Для изменений используйте POST с защитой от CSRF и параметризованные запросы. Для разработки используйте демоданные. Обе версии оформления проверяйте отдельно.

Для совместной работы используйте отдельные ветки и [журнал команды](journal/README.md). Перед передачей запустите `npm test`. Навыки проекта доступны в [`.agents/skills/`](.agents/skills).
